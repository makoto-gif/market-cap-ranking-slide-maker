# 時価総額ランキング推移スライドメーカー

日本・世界の時価総額ランキングの推移を「未来予測が重要」というメッセージ付きのスライドにして、PNG / PPTX でダウンロードできる静的サイトです。

## 機能

- **日本 / 世界の切り替え** — ワンクリックで市場を切り替え
- **企業の選び方**
  - 上位N社モード（3 / 5 / 7 / 10社、既定は主要5社）
  - 企業を選ぶモード（チェックボックスで特定企業を自由に選択）
- **期間指定** — 開始年・終了年を 2016〜2026 の範囲で指定
- **未来ゾーン** — 終了年以降に「? 次の覇者は？」の未来ゾーンを表示（ON/OFF可）
- **タイトル編集** — 自動生成タイトルを自由に上書き可能
- **ダウンロード**
  - PNG（3840×2160 の高解像度スライド画像）
  - PPTX（16:9 のPowerPointファイル。[pptxgenjs](https://gitbrent.github.io/PptxGenJS/) を同梱）
- **ランキングパネル** — 表示中の企業の順位・時価総額・期間内の順位変動を一覧表示

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動作します。

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages 等の静的ホスティングにそのまま配置できます。

## ファイル構成

```
index.html            # 画面レイアウト
css/style.css         # スタイル
js/data.js            # 時価総額データ（2016〜2026、単位: 10億USD）
js/chart.js           # Canvas によるスライド描画エンジン（1600×900 デザイン座標）
js/app.js             # UI状態管理・ダウンロード処理
js/vendor/pptxgen.bundle.js  # PPTX生成ライブラリ（同梱）
```

## データについて

- 2016〜2025年は各年末、2026年は2026年7月時点の概算値です。
- 出典: CompaniesMarketCap 等をもとにした概算値であり、投資判断には利用しないでください。
- データの更新は `js/data.js` の `MARKET_DATA` を編集してください。
